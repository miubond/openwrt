# MP716 1.0.2 完整管理后台集成

固件版本保持 1.0.2，后台修订为 `1.0.2-full.1`。原镜像中的 Vue 应用仅提供固件验签；本次复用现有完整 Vue 页面，并将生产适配器从原厂 CGI 切换到原生、需要 rpcd 会话认证的 `/cgi-bin/mp716/` 接口。入口为 `http://192.168.199.1/mp716/`。

## 已接通范围

| 页面 | 实际后端 |
| --- | --- |
| 首页、设备信息、日志 | system / network ubus、UCI、logread |
| WAN 配置及状态 | 有线 DHCP、静态地址、DNS、MTU、MAC；保留既有 eth0.2 |
| LAN 配置及状态 | LAN 地址和掩码；保留桥接与交换机配置 |
| DHCP | 地址池、租期、静态租约、现有租约 |
| 无线基础、高级、ACL | mac80211 UCI、hostapd、iw；保留已有密钥、接口及校准数据 |
| 终端管理 | 实际 DHCP、IPv4 邻居、无线关联；独立 nft 终端禁止列表 |
| 固件管理 | 原生上传验签入口；生产刷写继续关闭 |

VPN、4G、QoS 等未适配功能显示“暂不可用”，不返回虚假的成功。当前未安装 PPPoE 支持，因此不展示 PPPoE 和移动 WAN 选项。交换机 LAN 端口使用 P0–P3 标签，避免将物理编号假定为 LAN1–LAN4。

无线高级设置仅展示当前 mac80211 支持的参数。DTIM 和原厂专有保护/突发/前导码参数暂不开放；DTIM 在精简 hostapd 中的配置接入仍为 TODO。Beacon 写入无线设备节，与运行中的 hostapd 设备配置读取位置一致。

## 配置安全与回滚

- 变更前保存原始配置内容，全部输入通过检查后才提交 UCI；只修改请求涉及的配置项。
- 网络、无线及 DHCP 变更需要确认，默认 90 秒，允许 30–180 秒。
- 每个任务绑定登录会话；同时仅允许一个待确认任务。
- `mp716-admin` procd 服务每 5 秒检查一次截止时间。关闭网页后仍会回滚；待确认记录跨重启保存，在启动时恢复。
- 截止时间使用单调运行时间，并校验 boot ID，避免校时影响回滚。
- 回滚恢复原文件；后台显示服务端状态，撤销后重新读取页面参数。
- 终端禁止使用独立 `inet mp716_access` 表，不改写 fw4 配置；保护正在操作的管理终端。
- 密码读取返回掩码，保存掩码表示保留已有密钥。

## 保留的固件校验边界

本次没有更改 `.mp716upd` 签名格式、升级引擎或刷写开关。当前 LAN sysupgrade 镜像按原有规则不包含 CI 测试公钥；直接验证 CI 的 `test.mp716upd` 会返回 `public key cannot be read`，`signature_checked: false`、`flash_write: false`。未将每次构建生成的测试公钥擅自安装为生产信任根。生产签名公钥的配置需要单独完成；此结果不影响本次网络、无线和终端管理接口验证。

## 后续构建

`npm ci --prefix web` 后执行 `npm run --prefix web build`。现有 CI 继续通过 `integration/ram-web/stage.py --web-dist web/dist` 将完整页面、原生模块和回滚服务加入镜像，无需另一个前端仓库。

路由器上的现有配置由本次部署保留；重新构建镜像不会自动携带某台路由器的私有设置，后续升级仍应走原有配置迁移和保留流程。
