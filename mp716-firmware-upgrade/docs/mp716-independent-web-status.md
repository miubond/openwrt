## 尚未完成的设备功能

不能将“完整页面可构建”当作“所有设备功能已适配”。新增的原生系统管理、诊断和 VPN 代码仍在接入阶段：还需要安装、路由注册、所需系统软件包、服务启动与停止、真实运行状态及完整的端到端验收。VPN 的外部互通也没有验收。隔离夹具通过不代表这些服务已经在生产设备运行。

当前 Web 包保持 `UNVERIFIED`，要求部署前检查设备 API 版本及清单中的全部必需路由。缺少接口时不得直接覆盖现机后台，也不得用空页面或伪造成功替代服务实现。本轮未将新增原生服务部署到现机。

1.0.4 固件的构建、原始签名包网页验签与配置保留已经完成，详见 [1.0.4 真机网页验签报告](mp716-1.0.4-web-signature-test.md)。设备仍运行 1.0.3；1.0.4 本轮未刷写。
