# MP716 1.0.3 保留配置升级与真机测试

2026-11-18，设备所有者明确授权使用刚完成 GitHub 构建的 1.0.3 升级 MP716，保留原 Wi-Fi、管理地址和现有配置，并验证完整后台、有线、Wi-Fi 与 WAN 上网。本次已执行实际升级和重启。

## 镜像、备份和升级

- 来源：[GitHub Actions #44259651926](https://github.com/miubond/openwrt/actions/runs/44259651926)，构建提交 `c40b968a50b09ae35e0e812e1aff435c22fb5eb7`。
- 使用同次已验签包对应的原始 sysupgrade 镜像，5,570,823 字节，SHA256：`1c26c9728c8708737780a174a962d9d5e413b59a2e246fe2aefa75f3772cb5ed`。
- 刷前将保护分区和完整 firmware 分区顺序读取到电脑，保存为 8,388,608 字节的 Flash 备份，SHA256：`67261cbd5441f693ed34626edd658a6782566004f28de81a947819b8f11cab06`。备份读取直接通过 SSH 传到电脑，没有在设备 `/tmp` 保存整片 Flash。
- 使用设备自带 `sysupgrade -b` 生成当前配置归档，8,061 字节，SHA256：`1a8bfcddd73e9c91e1bdfb54473f5ed25b17d1bc60f31e95ef2d5831a71f26be`。确认包含网络、无线、DHCP、防火墙、管理员密码和 SSH 主机密钥。
- 上传后完整读回镜像与配置归档并比对；`sysupgrade -T` 和带同一配置归档的 `sysupgrade -T -f` 均返回 0。
- 通过电脑有线接口 9 执行一次标准 `sysupgrade -f 配置归档 sysupgrade.bin`。没有使用强刷参数、直接调用原始 MTD 写入命令或修改生产在线升级开关。

SSH 在升级关闭会话阶段断开；约四分钟内在原地址重新通过有线连接。以下以重启后的 ROM、配置、实际服务和网络测试确认结果，不以升级命令发出或日志结束作为成功依据。
